# opencv_image_proccesing_studio
Aplicatie desktop de procesare a aimaginilor realizata inPython cu Tkinter si OpenCV; include peste 16 filtre personalizate precum convolutii spatiale, detectie de muchii Canny, transformari afine si deformari in coordonate polare (vartej/valuri), alaturi de ajustari de contrast si frecventa.
